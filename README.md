# Query Duel

Browser 3D 1v1 shooter. Play solo vs bot or with a friend (peer to peer, no sign in).

Host a match, press Copy invite link, send it to your friend.

Not affiliated with Valve. Models are CC-BY (mrgulper/gayz, DevWolf11/Cam-Strike on Sketchfab), textures and sounds CC0. Full credits in the in-game Credits screen.
